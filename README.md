# 鳥仕足球隊 數據分析網站

台南鳥仕足球俱樂部（D LEAGUE 2026/27 L3）的比賽數據、失球分析與 2D 站位圖。

網站：https://wazzabenedict.github.io/niaoshi-fc/

## 頁面

- **總覽**：戰績、進失球時段分布、失球原因統計、失球當下比分、射手榜、積分榜、賽程
- **比賽**：每場的事件時間軸、先發陣容、失球分析（原因標籤＋2D 站位圖）、賽後檢討
- **球員**：進球、助攻、出場分鐘、在場進失球（+/−）
- **戰術板**：預設戰術圖與自由戰術板
- **紀錄**：場邊或看影片時記錄先發、換人、進失球，替每個失球選原因、畫站位圖

## 怎麼更新資料

1. 在「紀錄」頁記好（資料先存在自己的裝置，可按「預覽草稿」檢查）
2. 按「複製全部資料」
3. 到 GitHub 編輯 `data/matches.json`，全部取代後 Commit
4. 約 1 分鐘後網站更新

## 檔案

- `data/team.json`：球隊、名單、積分榜
- `data/matches.json`：每場比賽、事件、先發、站位圖、賽後檢討
- `data/boards.json`：戰術板預設圖
- 站位圖座標：x 0–100（左→右），y 0–100（上＝對方球門，下＝鳥仕球門）

純靜態網站，不需要建置，GitHub Pages 直接發佈。
